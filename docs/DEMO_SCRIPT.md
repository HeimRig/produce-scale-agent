# 演示视频分镜（目标 8–10 分钟）

| # | 时长 | 画面 | 旁白要点 |
|---|---|---|---|
| 1 | 40s | 设备全景，手指按下脚踏 | 一句话说清是什么：一台自己完成交易的秤 |
| 2 | 30s | 关闭说明：只接一根电源线，无电脑 | 强调边缘部署，不是"树莓派远程连服务器" |
| 3 | 60s | 放上苹果，屏幕显示识别置信度 | 讲模型：MobileNetV3-Small 微调，fp32 6.39MB，P50 2.5ms；顺带说 int8 试过但掉点 |
| 4 | 40s | 特写秤盘读数跳动到稳定 | 讲采样策略：7 次取中位数，极差判稳 |
| 5 | 50s | 语音播报 + 小票吐出 | 讲延迟预算：闭环 ≈1.2s（语音异步不计入） |
| 6 | 90s | 连续 5 单不同蔬果，含一次遮挡误识别 | 讲降级：置信度低重拍、人工选品兜底 |
| 7 | 60s | 拔网线，再跑一单 | 讲离线能力：本地模型 + 本地 TTS |
| 8 | 60s | 电脑端调 MCP，用自然语言让秤干活 | 讲工具层解耦，任何 Agent 能接 |
| 9 | 90s | 性能仪表盘：P50/P95 延迟、内存、准确率 | 数据说话，别只说"很快" |
| 10 | 40s | 收尾，回到设备全景 | 成本 ¥655，可复制 |

拍摄注意：

- 补光灯常开，避免顶光在果皮上打出高光斑
- 小票正面特写要能看清金额和单号
- 录制屏幕时把置信度、延迟打在角落，比口头说可信
