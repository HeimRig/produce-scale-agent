- 选阈值规则：误拒率 ≤ 7% 的前提下，尽量多拦错例

## 选中的阈值

`CONF_THRESHOLD = 0.45`，`MARGIN_THRESHOLD = 0.10`

- 误拒（正确商品被拦）：6.9%
- 拦住的错例：77%（30 张错例中）
- 保留样本准确率：96.8%（222 张）

## 边界

- 留出集全是正样本，算不出「未知物体检出率」。上表的误拒率是真实值，
  拦住错例的比例只是代理指标：错例和「压根不是商品」不是一回事。
- 要拿到真实的未知检出率，得拍一批非商品图（空托盘、手、手机、桌面）放进
  `data/unknown_test/`，再跑一次本脚本。
