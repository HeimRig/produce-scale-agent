# 30 秒演示录制操作卡

用途：README 首屏那张 GIF、简历里的项目链接、面试前的 30 秒预热。
用笔记本摄像头 + 真模型，秤用 mock（重量固定播种），不需要买任何东西。

---

## 一、准备（约 5 分钟）

**1. 改 `config.py` 两行**，让摄像头变成真的：

```python
CAMERA_BACKEND = "webcam"     # 原来是 "mock"
WEBCAM_INDEX = 0              # 笔记本内置摄像头一般是 0，外接的可能是 1
```

秤保持 `SCALE_BACKEND = "mock"`，语音 `TTS_BACKEND` 保持 `"auto"`（已装 edge-tts 会自动走它）。

**2. 摄像头自检**，确认能出图、分辨率对：

```bash
python scripts/cam_check.py
```

窗口里看到自己就对了，按 `q` 退出。打不开就换 `--index 1`。

**3. 试跑一次**，确认拿到的是真识别而不是 mock 的哈希猜类：

```bash
python -m app.main --weight 480
```

看两处：`[后端]` 里 `vision` 是 `onnx`、`camera` 是 `WebcamCamera`；终端里识别置信度在 80% 以上。

**4. 摆场景**：桌上放白纸或深色桌布当背景，拿一个苹果/橘子/香蕉。光线从侧面来，别让顶灯在果皮上打高光。

---

## 二、录制（约 10 分钟）

**录制工具二选一**

- 最省事：`Win + G` 打开 Xbox Game Bar → 点录制。录的是全屏，画质够用，自带 mp4。
- 更好看：`Win + Alt + R` 直接开始/停止录制（同一套）。
- 要后期剪：装 OBS，场景切成"显示器采集 + 麦克风"，输出 1080p30。

**录制前固定窗口**：终端字号调大（至少 18pt），窗口拉到 1280×720 左右，避免录出来字太小。

---

## 三、30 秒脚本

| 时间 | 画面 | 你说的话 / 屏幕上的东西 |
|---|---|---|
| 0–3s | 桌面全景，手拿果子入镜 | "这是一台自己完成交易的秤。" |
| 3–8s | 把果子放到摄像头前（或架子上） | 终端打印 `识别 苹果 87%` |
| 8–12s | 终端滚动：称重、计价 | "重量、单价、金额，一次算完。" |
| 12–16s | 喇叭出声（波形或字幕提示） | 语音："苹果，零点四八公斤，共三点八四元" |
| 16–20s | 小票内容出现在终端 | "小票同时落盘。" |
| 20–25s | 切到 `docs/architecture.svg` 或终端里的耗时行 | "闭环 107 毫秒，模型 6.39 MB，跑在树莓派上。" |
| 25–30s | 回到桌面 | "同一套能力还能被 MCP 调用。" |

**要点**：不要在视频里解释代码。30 秒只讲"它能干什么"和"多快"，剩下的留给 README。

## 四、后期与落地

**转 GIF**（装 ffmpeg 后一行）：

```bash
ffmpeg -i demo.mp4 -vf "fps=12,scale=880:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" -loop 0 docs/demo.gif
```

目标 **5 MB 以内**，超过 10 秒的片段没必要，GitHub 上大 GIF 加载很卡。

**放进 README**：首屏数字表格下面加一行

```markdown
![demo](docs/demo.gif)
```

**保留原片**：`demo.mp4` 放仓库根目录或云盘，简历里放链接比 GIF 清楚。
