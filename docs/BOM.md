## 三、接线表

| 器件 | 引脚 | 树莓派 5 |
|---|---|---|
| HX711 VCC | — | 3.3V (pin 1) |
| HX711 GND | — | GND (pin 6) |
| HX711 DT / DOUT | — | GPIO5 (pin 29) |
| HX711 SCK | — | GPIO6 (pin 31) |
| 摄像头 | CSI | CAM0 排线口 |
| 打印机 | USB | USB3 口（或 UART `/dev/ttyUSB0`） |
| 声卡 / 麦 | USB | USB2 口 |
| 脚踏开关 | — | GPIO17 (pin 11) + GND，内部上拉 |

> 树莓派 5 用 lgpio，**不要用 RPi.GPIO**（Pi 5 上 GPIO 寄存器已改，RPi.GPIO 直接报错）。代码里已按 lgpio 写。

## 四、采购顺序建议

1. 先买打印机 + 热敏纸（阻塞"打印小票"这一环，最容易卡）
2. 再买托盘 + 补光灯（影响识别准确率，比换模型有效）
3. USB 声卡最后买（edge-tts 可以先在电脑上验证音色）
